## Decisões

- O primeiro teste usa `rehearse`, que executa os gates contra Preview e não altera Production.
- `promote` e `rollback` só podem executar quando o workflow é iniciado a partir de `main` e após acesso ao Environment `Production`.
- O workflow não automatiza rollback de banco.
- Migration de Production usa somente `DATABASE_URL_UNPOOLED` do Environment protegido.
- O go-live continua bloqueado por `DEC-004`; preparar o mecanismo não autoriza publicação.
