## Decisões

- O primeiro deployment é Preview; produção permanece fora deste corte.
- A região de execução é `gru1`.
- O runtime usa Node 22; `package.json` aceita patches compatíveis a partir de `22.12.0`, enquanto `.node-version` e `.nvmrc` preservam a referência local.
- Preview recebe somente credenciais da branch Neon `preview`.
- Migrations não executam no build nem no boot da aplicação.
- Nenhum segredo é gravado no Git, em documentação ou em logs.

## Desvio operacional

A Vercel CLI instalada encontrou uma cadeia de certificado autoassinado antes de consultar a conta. A verificação TLS não será desativada; o vínculo e o deployment serão feitos pelo painel autenticado da Vercel.

O certificado raiz do Kaspersky já confiado pelo Windows foi fornecido ao Node apenas durante os comandos da CLI. Nenhuma verificação TLS foi desabilitada.

Na criação do projeto, a Vercel classificou automaticamente o primeiro deploy como Production, mesmo sem `--prod`. Esse artefato contém apenas a aplicação estática, sem variáveis ou acesso ao Neon. Os deployments seguintes foram confirmados como Preview; nenhuma nova promoção de produção foi executada.
