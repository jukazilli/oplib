## Decisão

A pesquisa será executada por `Enter` ou `Pesquisar`, nunca a cada tecla. A paginação usa data de publicação decrescente e ID como desempate. Filtros públicos usam slugs; parâmetros inválidos retornam aos padrões seguros. Feed e Grade abrem a página canônica da publicação, preservando a pesquisa pelo histórico do navegador.
