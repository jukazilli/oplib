## Decisão

`recordAdminAuditEvent` recebe a transação do comando de sucesso para que mudança e evidência confirmem juntas. Falhas relevantes, quando não houver mutação confirmada, podem ser registradas em operação separada. A API não recebe payload arbitrário; entidade deriva da ação e os metadados aceitam apenas código de erro estável.
