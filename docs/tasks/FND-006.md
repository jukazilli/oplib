## Decisões

- O schema inicial materializa as entidades do modelo conceitual aprovado.
- O runtime usa `DATABASE_URL` com pooling; Drizzle Kit usa exclusivamente `DATABASE_URL_UNPOOLED`.
- Nesta fase, ambas as URLs usam `neondb_owner`; roles customizadas ficam como hardening futuro e não bloqueiam migrations.
- Migrations nunca são importadas nem executadas pelo runtime da aplicação.
- Extensões PostgreSQL não são habilitadas preventivamente.

## Provas
